# MyPet — Aplicativo Mobile de Rede Social para Tutores de Pets

## Sobre o projeto

O **MyPet** é um aplicativo mobile desenvolvido para a disciplina **Desenvolver Aplicativos para Dispositivos Móveis e IoT**.

A proposta do aplicativo é funcionar como uma **rede social pet**, voltada para tutores de animais de estimação. O app busca reunir, em um único ambiente, funcionalidades relacionadas à interação entre usuários, compartilhamento de conteúdos, discussões sobre pets, marketplace, localização do animal e gerenciamento do perfil do usuário.

Nesta primeira versão, o projeto apresenta uma base funcional do aplicativo, com telas organizadas, navegação entre páginas e uso de dados simulados para representar as principais funcionalidades planejadas.

## Funcionalidades implementadas

Nesta fase do projeto, foram implementadas as principais telas e estruturas visuais do aplicativo, incluindo:

- Tela inicial/feed com publicações relacionadas a pets
- Navegação entre telas por meio de menu inferior
- Tela de discussões/comunidade
- Tela de marketplace
- Tela de localização do pet
- Tela de perfil do usuário
- Telas relacionadas ao cadastro e gerenciamento de pets
- Telas de autenticação e onboarding
- Uso de dados mockados para simular posts, discussões, produtos, animais e pets perdidos
- Interface organizada e utilizável para validação da proposta inicial

As funcionalidades desta fase ainda utilizam dados simulados, sem integração com backend ou banco de dados real.
